# 착취 계산기

여러 플레이어가 들어있는 txt 내용을 붙여넣어 길드오피서가 개인별 +/- 정보를 확인하는 로컬 웹 프로그램입니다.

## 실행 방법

1. `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. txt 내용을 입력 칸에 그대로 붙여넣습니다.
3. `누적에 반영`을 누릅니다.

`Ctrl + Enter`로도 누적에 반영할 수 있습니다.

## 지원 포맷

아래처럼 따옴표가 있는 탭 구분 txt를 지원합니다.

```txt
"날짜"	"플레이어"	"목적"	"수량"
"2026-05-31 05:55:36"	"Alice"	"입금"	"50"
"2026-05-31 05:52:56"	"Bob"	"출금"	"-10"
```

기존처럼 따옴표가 없는 탭 구분 형식도 계속 지원합니다.

## 4주 데이터가 사라지는 경우

원본 txt가 최근 4주치만 제공된다면, 과거 행은 나중에 원본에서 사라질 수 있습니다.
이 경우 `누적에 반영`을 눌러 현재 붙여넣은 행을 브라우저에 저장하세요.

- 이미 저장된 행은 중복으로 더하지 않습니다.
- `플레이어별 누적 합계`에서 개인별 최종합, 입금, 출금, 최초 기록일, 최근 기록일을 확인할 수 있습니다.
- 개인 플레이어는 검색창에 자신의 이름을 입력해서 본인 정보만 확인할 수 있습니다.
- 플레이어 검색창은 저장된 플레이어 이름을 자동완성으로 제안합니다.
- 표의 `플레이어`, `최종합` 제목을 클릭해 오름차순/내림차순 정렬할 수 있습니다.
- 브라우저 데이터 삭제에 대비해 `백업/초기화`에서 JSON 백업을 보관할 수 있습니다.
- 가장 최근 날짜 기준 28일보다 오래된 원본 행은 개인별 합계로 자동 압축합니다.
- 최근 28일 행만 원본으로 남겨 중복 제외에 사용하고, 과거 데이터는 개인별 합계와 최초/최근 기록일만 보관합니다.
- 백업 파일은 `과거 개인별 합계 + 최근 원본 행` 포맷이라 장기 사용 시 크기가 크게 늘지 않습니다.
- 이전 버전에서 받은 백업 파일도 계속 불러올 수 있습니다.
